# Board

- In chat: `foundry board` prints the fixed groups in their fixed order (진행 중, 오너 대기, 팀 대기, 대기열, 머지됨·릴리스 대기, 릴리스 완료, 완료, 취소), each with its count; paste it as a code block. Detail for one row: `foundry unit show <id>` (summarize it; do not dump JSON at the owner).
- Side pane: the owner types `/foundry-board`. It opens a pane beside the chat (fullscreen terminal layout docks it as a sidebar); each row is a button that opens the unit's detail, with a back button. It refreshes every 30 seconds. Close it with its close mark; `/foundry-board` opens it again.
- Browser: `~/.local/state/foundry/board.html`, regenerated by every foundry command and by the watcher; it reloads itself every 60 seconds and expands a row's detail on click.

The board is derived from state; nobody edits it. A row's group and its state cell both come from one function
(board.py `unit_state`): a finished unit with a PR still open is 팀 대기, one with a merged PR no release tag holds yet
(in a repo with a release step) is 머지됨·릴리스 대기, a done release unit or one whose PRs are released is 릴리스 완료.

## PRs that are not the owner's

When the owner says a PR or a whole repo on the board is not theirs (「내 담당 아님」, 「제외해줘」), run
`foundry pr drop <owner/repo#n> --reason "<the owner's words>"`, or `foundry pr drop --repo <owner/repo | owner/*>
--reason "..."` for every PR there, new ones included; its open pr-aging / pr-orphan cards close by themselves.
Answering a pr-aging card with `drop` does the same for that PR. `foundry pr undrop <ref> | --repo <pattern>` undoes it.

## Tidying the finished list

When the owner asks to clean up the board's finished units (「완료된 거 정리해줘」, 「보드 정리해줘」), archive them:
`foundry board archive --all-done --by foreman --quote "<the owner's exact words>"` (or `--older 3d` for older ones;
`--dry-run` lists them first). It moves 릴리스 완료, 완료 and 취소 units into the archive view
(`foundry board --archived`), records only, and deletes nothing; 팀 대기 and release-wait units always stay.
Units finished longer than prefs `board.archive_days` (7) ago move there by themselves. Worktree, docker and session
cleanup is the foundry-housekeeping skill, not this.

End every board answer with this line, so the owner knows the pane is a different thing from this skill:

```
pane: /foundry-board
```

This skill is `foundry-status` on purpose: `/foundry-board` is the mod's pane toggle and the only command by that name.
